A page builder is a promise that someone else will handle the details. In my
experience, that promise breaks the moment your client asks for something the
builder didn't anticipate.

## The case for hand-written code

- It loads faster. No 400 KB of JavaScript to render a heading.
- It's readable. When you open the file in 2027, you'll understand it.
- It's yours. No vendor can change the terms on code you wrote.

## What it costs

Time, mostly. The first version takes longer. But the tenth change to a
hand-built site is faster than the tenth change to a page-builder site. That's
the trade I make every time.
