Каждый проект, за который я берусь, начинается одинаково: с направляющих. Не
потому что я педант, а потому что решение о том, где что стоит, **до** решения о
том, как это выглядит, экономит недели переделок потом.

## Порядок

1. **Линии** — где контент, где пустота.
2. **Сетка** — колонки, отступы, поверхность, которая держит вёрстку.
3. **Шрифт** — кегль, насыщенность, переносы. Одна гарнитура. Может, две.
4. **Цвет** — бумага, тушь, один акцент. Это всё.
5. **Код** — та же дисциплина, выраженная в компонентах.

К моменту, когда я открываю редактор кода, дизайн уже решён. Сборка
механическая.

## Почему порядок важен

Большинство дизайнеров работают в обратном направлении. Выбирают цвет, находят
шрифт, ставят главное изображение, потом решают, где будут кнопки. Результат
выглядит нормально, пока не понадобится добавить секцию, которая не вписывается
в шаблон, или второй язык, или мобильную версию, о которой никто не подумал.

Работа в обратном порядке — линии, затем сетка, затем шрифт, затем цвет, затем
код — означает, что структурные решения принимаются первыми. Как только скелет
правильный, всё последующее — это настройка, а не изобретение.

Изображения, тексты, анимации — всё встаёт в рамку, которая уже была
спроектирована, чтобы их удерживать. Рамка не борется с содержимым. Содержимое
не борется с рамкой.

## Как это выглядит на самом деле

Сначала рисуются направляющие. Две вертикальные линии для границ контента. Две
горизонтальные — для верха заголовка и базовой линии навигации. Больше ничего
пока нет.

Затем сетка. Двенадцать колонок, постоянные отступы, максимальная ширина
контента. Это не украшение — это обещание о том, где будут стоять вещи. Каждый
элемент, который появится позже, будет выровнен по ней — или сдвинут для
осознанного исключения.

Шрифт идёт третьим. Одна гарнитура, выбранная по тому, как она читается в тех
размерах, в которых будет использоваться. Переносы настроены строка за строкой.
Контраст насыщенности используется только там, где он заслуживает место.

Цвет идёт четвёртым. Бумага для фона, тушь для текста, один акцент для редких
моментов, которые заслуживают подчёркивания. Не палитра — а обязательство.

Код идёт последним. К этому моменту всё решено. Компоненты пишутся сами. CSS
пишется сам. Нет угадывания, потому что нечего угадывать.

## Что это значит для клиента

Вы получаете дизайн, который держится. Не только в день сдачи — через год, когда
нужно добавить новую страницу продукта. Через два года, когда нужен второй язык.
Через пять лет, когда нужно передать его другому разработчику.

Дисциплина, которая входит в вёрстку, — та же дисциплина, которая входит в
кодовую базу. Один человек, делающий и то, и другое, означает, что замысел
переживает передачу, которой не происходит.

## Суть

Хороший метод скучен. Он работает одинаково каждый раз. Он убирает угадывание из
тех частей, где оно не нужно, чтобы те части, где оно нужно — идеи, тексты,
моменты удивления — получили настоящее внимание.

Сначала направляющие. Затем сетка. Затем шрифт. Затем цвет. Затем код. Именно в
этом порядке, всегда.
